## 三个问题的修法

### H（阻塞）探针页 TDLib 双实例锁冲突

真机报 `error 400: Can't lock file .../secure/tdlib/db/td.binlog, because it is
already in use by current program`。

TDLib 对一个 database_directory 持排他锁，锁的生命周期 = 客户端生命周期。

- `ProbePage` 新增可选 `reuseClient`，`tools_page` / `settings_page` 两个入口都传入
  `AppServices.client`
- 复用模式完全跳过 `TdClient.open` 与 `setTdlibParameters`，只发只读请求
- 挂载时调一次 `getAuthorizationState`：早先登录的客户端不会再发
  `updateAuthorizationState`，不主动查就会让链路按钮永远禁用
- `dispose` 不再关闭复用的客户端（频道页、视频流、resolver 还在用）
- 未登录（`services.client == null`）时仍自建客户端 — 此时不存在第二个实例，
  不冲突，探针页保留首次诊断能力

九步台账拆到 `ProbeProgress`，使判定可在没有 TDLib 原生库的情况下断言。

### I 视频页空态 vs 索引 184 条

- **I-1**：索引存所有媒体类型，单页 40 行可能全是图片。空列表不能滚动 → 触底分页
  永不触发 → 死锁。首屏改为循环补页直到 3 条视频或索引耗尽，上限 10 轮。
- **I-2**：`didUpdateWidget` 切回 Tab 只重新激活播放器，保留启动时的快照；
  `IndexStore` 也没有变更信号。新增单调 `revision`，在 `upsertAll` /
  `setFavorite` / `setWatermark` / `removeLocalChannel` 自增（open 重放时不自增）；
  视频页记录读取时的 revision，切回时比对，变了就释放播放器并重读。

### J 时长 chip 裁切

默认密度 + 12 pt 标签在 375 pt 下超出数点，最后一项显示成「5 分钟以」。改为
11 pt + `VisualDensity.compact` + 2 pt label padding；横向滚动保留作窄屏兜底。
